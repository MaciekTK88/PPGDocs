# Features

This section covers the plugin's primary features:

- terrain generation
- spline brushes for terrain shaping
- texture-masked terrain stamps
- invoker-driven terrain and foliage collision streaming
- planet navigation for AI
- planetary water
- multiple atmospheres and a camera-following skylight
- foliage
- cloud parameter updates
- gravity-relative controller utilities
- planet-relative editor camera navigation and surface-aligned actor placement
- double-precision plugin floating origin for very large worlds
